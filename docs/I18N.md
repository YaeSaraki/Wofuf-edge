# 国际化（i18n）

前端界面文案一律走 i18n，不在组件里写死中文。这份文档说清机制、约定，
以及当前还欠着的账。

---

## 1. 机制

### 语言包

每条文案同时带中英两种语言，放在**按模块划分的 `.ts` 文件**里：

| 文件 | 内容 | 命名空间 |
|---|---|---|
| `frontend/src/modules/app/utils/i18n/translations.ts` | 全站通用文案 | `app` |
| `frontend/src/modules/players/config/translation/index.ts` | 玩家模块通用文案 | `players` |
| `frontend/src/modules/players/config/translation/statisticsTranslation.ts` | 统计项、单位、排序 | `players` |
| `frontend/src/modules/players/config/translation/advancementsTranslation.ts` | 成就分组与标题 | `players` |
| `frontend/src/modules/players/config/translation/advancementsItemTranslation.ts` | 成就条目（裸 snake_case 键） | `players` |

条目长这样：

```ts
'search.result-count': {zh: '找到 {count} 位玩家', en: 'Found {count} players'},
```

语言包在模块入口被注册（`registerTranslations('players', …)`），**静态 import，没有动态加载**。

### 用法

```ts
import {translate} from '@S/services/i18n'

translate('players', 'search.placeholder')                       // 纯文案
translate('players', 'search.result-count', {count: 12})        // 带变量
hasTranslation('players', 'stats.item.ANIMALS_BRED')             // 这条有没有名字
```

- `translate(命名空间, key, 参数?)`：找不到 key 时**原样返回 key**（界面上会出现一串键名），
  找到但当前语言缺文案时回落到英文。
- `hasTranslation(命名空间, key)`：用来判断"这条到底有没有名字"，
  用于"没有翻译就不渲染"这类场景（见 `StatisticsPanel.vue`）。

### 语言切换

- 语言取自 `localStorage`（用户上次的选择）→ 浏览器语言 → 默认 `zh`。
- 切换入口在导航栏的设置弹窗（`AppNavbar.vue`）。
- 支持 `zh` / `en` 两种语言。

## 2. 约定

### 新增界面文案必须走 translate()

组件里不许出现用户可见的中文硬编码。`scripts/check-i18n.sh` 会在 CI 里扫：

- `.vue` 的 `<template>` 段（文本节点 + `placeholder` / `alt` / `title` 等属性值）
- `.vue` 的 `<script>` 段与 `.ts` 文件里的字符串字面量

注释、`console.*` 输出、语言包文件本身不算。

### translate() 必须在模板或 computed 里调用

```ts
// ❌ 不会随语言切换更新：setup 顶层只求值一次
const label = translate('players', 'search.placeholder')

// ✅ 模板里直接调用
<span>{{ translate('players', 'search.placeholder') }}</span>

// ✅ 或者放进 computed
const label = computed(() => translate('players', 'search.placeholder'))
```

`AppNavbar.vue` 的导航项就是用 `computed()` 做的。

### 插值只用于文本节点

`translate()` 的 `{name}` 会被参数替换。**不要把插值结果塞进 `v-html`** ——
用户输入（比如搜索关键词）会变成 XSS 入口。文本节点 `{{ }}` 由 Vue 自动转义，是安全的。

### fallback 是英文

`translate()` 找不到当前语言的文案时回落到英文（`shared/services/i18n/index.ts`）。
所以新增条目**必须同时写 `zh` 和 `en`** —— `scripts/check-i18n.sh` 会检查这件事。
确实不需要英文时，显式写 `en: ''`（会被记账，不算失败）。

### 错误文案：service 层翻译，组件层零改动

后端错误响应是 `{success, code, data, message}`：`code` 是稳定错误标识（`TURNSTILE_REQUIRED_ERROR` 等），
`message` 是中文原文。**要翻译的是 code，不是 message。**

错误文案的产生在 service 层：

```ts
// 两级查找：后端 code → 全局映射；没有 code → 这个接口自己的兜底 key
formatApiError('error.player-profile', response.data.code)
```

映射与工具函数在 `frontend/src/shared/infra/api/apiErrors.ts`，
后端加新 code 时在前端加一条映射即可，**后端不用改**。

组件层不用改：service 返回的 `Result.error` 已经是当前语言的文案，组件照旧显示即可。

## 3. 全仓硬编码中文审计

审计时间：2026-10-30。扫描范围：`frontend/src/` 全部 `.vue` 与 `.ts`。

### 用户可见的界面文案（欠账 6 处，已在 `scripts/i18n-allowlist.txt` 记账）

| 文件 | 文案 | 性质 |
|---|---|---|
| `views/ServerStatsView.vue` | 获取服务器状态失败 | 错误提示 |
| `views/PlayerView.vue` | 玩家信息获取失败（玩家不存在或权限不足） | `throw` 的 Error.message，会显示 |
| `views/PlayerView.vue` | 获取玩家信息失败 | errorTip 兜底 |
| `views/PlayerView.vue` | 暂无玩家数据 | 空状态 |
| `playerProfile/PlayerProfilePanel.vue` | 获取玩家皮肤失败 / 玩家皮肤获取失败 | errorTip + throw |
| `statistics/StatisticsPanel.vue` | `${value} 块` | 单位（语言包已有 `stats.unit.blocks` 却没接上） |

### 不是文案，别误判

- **注释**：绝大多数中文都在注释里。`AdvancementGroups.ts` 109 行中文**全是行尾注释**；
  `AppNavbar.vue`、`DraggablePopup.vue`、`AdvancementsPanel.vue`、`YesterdayOnlineList.vue`
  的中文也都只是注释。
- **调试输出**：`console.*` 里的中文不显示给用户，不算。
- **死数据**：`config/statisticGroups.ts` 的 `name` 字段（"移动统计"等）—— 界面读的是
  语言包的 `stats.group.*`，`name` 没人用。
- **品牌名**：`shared/config/theme.ts` 的主题名与描述（"液态玻璃"/"Memphis 孟菲斯"）——
  主题是构建期决定的，界面里不显示它们。
- **语言自称**：语言切换器里的"中文"。

### 语言包里定义了但代码里没用上的 key（80 个）

分三类，本轮不动（只记账）：

1. **给另一版服务器信息页预留的**（`status.info.*` / `status.system.*` / `status.quickLinks.*`
   / `status.stats.*` / `status.players.*`，约 30 个）—— 当前页面是另一套设计。
2. **像漏接的**：`advancements.group.STORY` 等 6 个 —— 成就分组标题现在直接渲染英文标识符
   `STORY`/`ADVENTURE`，中文翻译在包里却没接上。**这是"英文没被翻译"，不是硬编码中文。**
3. **死数据/备而不用**：`stats.unit.*` 6 个、`stats.sort.*` / `stats.filter.*` / `stats.time.*` 等。
